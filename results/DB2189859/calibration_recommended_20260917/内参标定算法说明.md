# 本次相机内参标定算法

## 数据与软件

- 相机：实际连接的 **MV-CS023-10GC**，序列号 `DB2189859`；原图尺寸 `1920×1200`。这份内参不属于最初计划的 MV-CS050-10GC。
- 输入：`/home/ybbb/桌面/相机内参标定/preview_DB2189859_slider_fit_20260917` 中的 34 张原始 PNG，均检出完整棋盘。
- 棋盘：10×7 个方格，对应 **9×6 个内角点**。标称格距 50 mm；本次按 50 mm 计算，尚需用尺确认打印成品的真实格距。
- 实现：本目录的 [`calibrate.py`](calibrate.py)。运行环境为 Python 3.10.12、OpenCV 4.13.0、NumPy 1.26.4。

## 计算步骤

1. 对每张 1920×1200 图像转灰度，用 OpenCV `findChessboardCornersSB(gray, (9, 6))` 定位 54 个亚像素内角点。只有角点检出完整、尺寸一致的图像进入计算；本批次为 **34/34 张**。
2. 给棋盘上的角点赋予平面三维坐标：`(50i, 50j, 0) mm`，其中 `i=0…8`、`j=0…5`。每张图像的角点像素坐标与这些棋盘坐标一一对应。
3. 使用 `cv2.calibrateCameraExtended` 同时求相机内参、畸变参数和每张图的棋盘位姿。计算时使用 `cv2.CALIB_FIX_K3`，将三阶径向畸变 `k3` 固定为 0；停止条件为最多 100 次迭代或变化量小于 `1e-10`。
4. 用重投影误差检查结果：将棋盘角点按求得的参数投影回每张图，比较预测像素位置与检测位置；函数给出整体及逐张 RMS。

该方法属于**多视角平面棋盘格针孔相机标定**。OpenCV 先从平面棋盘视角建立参数初值，再通过非线性优化使重投影误差尽量小。具体 API 与畸变模型见 [OpenCV 相机标定教程](https://docs.opencv.org/4.13.0/d4/d94/tutorial_camera_calibration.html) 和 [calib3d API 文档](https://docs.opencv.org/4.8.0/d9/d0c/group__calib3d.html)。

## 相机模型

内参矩阵为：

```text
K = [[fx,  0, cx],
     [ 0, fy, cy],
     [ 0,  0,  1]]
```

相机坐标归一化为 `x=Xc/Zc`、`y=Yc/Zc`，设 `r²=x²+y²`。本次的径向、切向畸变模型为：

```text
xd = x(1 + k1·r² + k2·r⁴) + 2p1·x·y + p2(r² + 2x²)
yd = y(1 + k1·r² + k2·r⁴) + p1(r² + 2y²) + 2p2·x·y
u  = fx·xd + cx
v  = fy·yd + cy
```

其中 `k3=0`。输出文件仍按 OpenCV/ROS 常见顺序保存五个位置 `[k1,k2,p1,p2,k3]`，第五个值是 0。每张图像都有独立旋转、平移外参；所有图像共用一组 `K` 和畸变参数。

## 适用范围

- 角点横向覆盖约 `10.5%～79.3%`，纵向覆盖约 `16.8%～84.6%`。右侧和画面最外缘缺少足够约束；若后续需要整幅图像高精度去畸变，应补拍边缘及四角棋盘照片后重新计算。
- 8 张留出照片取自同一次拍摄，仅作交叉检查。第 35、36 张新增照片未参与拟合，完成了位置与重投影检查；仍缺少覆盖图像边缘的独立验证集。
- 方格距的实际测量值会影响外参平移所用的毫米尺度。改变相机、镜头、对焦、图像分辨率或 ROI 后应重新核查内参。

## 用一张新棋盘照片估算距离

棋盘可以任意平移或倾斜，只要能清晰检出完整 9×6 内角点，且相机、镜头对焦、分辨率和 ROI 与标定时一致。运行本地 [`measure_board_distance.py`](measure_board_distance.py)：

```bash
cd /home/ybbb/codex_prj/camera_intrinsics_mvs
./run.sh distance \
  --image /home/ybbb/桌面/相机内参标定/DB2189859/validation_images/001.png \
  --intrinsics /home/ybbb/桌面/相机内参标定/DB2189859/calibration_recommended_20260917/intrinsics.json \
  --square-mm 50 \
  --output /home/ybbb/桌面/相机内参标定/DB2189859/distance_001.json
```

将图像路径改为新照片的实际文件名，并将 `--square-mm` 改为打印成品的实测格距。脚本用 `solvePnP` 求棋盘相对于相机的位姿，输出两个不同量：

- `Optical center to board center`：相机**光心到棋盘中心的三维直线距离**。
- `Depth along optical axis`：棋盘中心沿相机光轴的深度，即相机坐标系的 Z 值。

卷尺从镜头前端或相机外壳量到棋盘的距离，和“从光心量起”有固定起点差异。若要用卷尺验证，推荐沿相机光轴移动棋盘一段已知距离，再比较两张新照片的 `Depth along optical axis` 之差。用同一批标定照片计算距离只能检查程序运行，不能替代独立验证。没有已知尺寸的棋盘或其他参照物时，单目相机不能仅凭一张任意场景照片求出绝对距离。

第 35 张照片按上述脚本计算：棋盘中心相机坐标约 `(-20.7, -123.1, 995.8) mm`，光心到棋盘中心约 `1003.6 mm`，重投影 RMS 约 `0.108 px`。详情在 [`distance_frame_0035.json`](distance_frame_0035.json)。

第 36 张照片计算得到棋盘中心约 `(-32.5, -105.1, 1310.3) mm`，光心到棋盘中心约 `1314.9 mm`，重投影 RMS 约 `0.067 px`。相较第 35 张，沿光轴深度增加约 `314.5 mm`。详情在 [`distance_frame_0036.json`](distance_frame_0036.json)。
